Brag

Setup

  1. Find your WoW folder

    The _forever_ folder inside your World of Warcraft install. Brag looks for it on its own; if it couldn't, pick it here.

  2. Install the Brag addon

  3. Connect Discord

    Brag posts to a Discord channel through a link that Discord makes for you. Get it like this:

    1. In Discord, right-click your server and pick Server Settings, then Integrations.
    2. Click Webhooks, then New Webhook, and choose the channel to post in.
    3. Click Copy Webhook URL and paste it below.

  4. Play!
